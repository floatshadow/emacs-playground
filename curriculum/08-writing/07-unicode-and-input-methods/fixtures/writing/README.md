# Lantern

Lantern turns a folder of Markdown notes into a small website. It runs
offline and keeps no state of its own.

## Features

- Markdown in, HTML out
- One command, no configuration

## Commands

| Command | What it does |
|---|---|
| lantern build | writes the site to out/ |

## Status

Lantern is a teaching example for the Emacs Playground course.
