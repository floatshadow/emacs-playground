# tally

tally counts the words, lines and characters of text files, like `wc`,
and remembers the totals of every run so you can see how a document
grows.

- [Install](install.md) tally and write your first `.tallyrc`.
- [Usage](usage.md) shows the everyday commands.
- The [FAQ](faq.md) answers the usual questions.

All settings live in one file, `.tallyrc`, in your home directory.
