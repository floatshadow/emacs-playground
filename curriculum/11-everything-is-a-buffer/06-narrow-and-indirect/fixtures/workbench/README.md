# workbench

Material for Part 11, "Everything is a buffer". Each folder belongs to
one or two lessons:

- `assets/`, `notes/release.md`: 11.1, copying out of Dired and Magit
- `photos/`, `docs/`, `notes/todo.md`, `site.tar`: 11.2, editing listings
- `broken/`: 11.3, a crate with two compile errors
- `tally/`: 11.4, 11.6 and 11.7, a small histogram crate
- `checks/`: 11.5, a test suite with failures
- `docs/guide.md`, `notes/plan.org`: 11.6, code inside documents
- `report/`, `scripts/`: 11.8, hooks
- `polyglot/`: 11.9, the capstone
